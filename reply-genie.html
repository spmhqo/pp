Prompt #4
Answer the following prompt in Bengali (India).

Rules:
- Use only Bengali (India).
- Always address the reader as "আপনি".
- Never use "তুমি" or "তুই".
- Use a natural Kolkata-style conversational tone.
- Use natural, modern Bengali (India).
- Avoid Bangladeshi vocabulary, spelling, and expressions.

PROMPT
Present the analysis in the following four-part structure:
Section | Analysis
1. Reader’s Issue | Identify the specific issue, problem, difficulty, or unmet need of the reader that the content addresses.
2. Proposed Solution | Determine whether the content provides a solution to that issue. If yes, clearly identify and state the solution. If no, state that no explicit solution is provided.
3. Functioning of the Solution | Analyse how the proposed solution functions. Identify its Process, Mechanism, and Structure, and explain how these elements work together to produce the intended effect.
4. Objective Outcome | Identify the objective outcome that results from the functioning of the solution. State what objectively changes, happens, or becomes possible as a result.
Analysis Rules
Base the analysis strictly on the content of the uploaded document.
Do not introduce ideas, solutions, mechanisms, or outcomes that are not supported by the document.
Clearly distinguish between what the document explicitly states and what can be reasonably inferred from it.
If any element cannot be identified from the document, state “Not identifiable from the document” rather than guessing.
Do not evaluate whether the solution is effective or desirable unless the document itself provides sufficient evidence for such an assessment.
